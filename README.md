# The hits changed. Just not all at once.

Six decades of the Billboard Hot 100, joined to Spotify's audio measurements, to ask what
actually changed about hit songs — and when.

**[Read the story →](https://gitnic-duke.github.io/AIPI-510-Project-1/)**

Course project for AIPI 510 (Duke). Nicholas Wang and Kuba Romanczuk.

## Quickstart

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python src/clean.py       # raw -> chart_entries.csv, songs.csv
.venv/bin/python src/features.py    # songs.csv -> songs_features.csv
.venv/bin/python src/visualize.py   # processed -> docs/figures
```

Each script prints a report and asserts its own invariants, so a broken run fails loudly
instead of producing quietly wrong numbers. Raw data is committed, so this works from a fresh
clone with no downloads. Every figure in the story is regenerated by the third script, and
each one's plotted values are exported beside it under `docs/figures/data/`.

## What we found

Songs counted once, in the year they first reached the chart. Six complete decades,
1960–2019: 27,549 songs, of which 23,039 carry all four Spotify audio scores.

- **Less cheerful, still danceable.** Median valence falls from 0.696 in the 1960s to 0.466 in
  the 2010s while danceability rises. Songs that are *both* low-valence and danceable go from
  6.3% of hits to 41.2%.
- **Short songs are coming back.** Median length runs 2:39 in the 1960s, 4:18 in the 1990s,
  3:35 in the 2010s. "Songs are getting shorter" depends entirely on where you start counting.
- **The acoustic shift happened early.** Median acousticness drops from 0.579 in the 1960s to
  0.124 by the 1980s, and barely moves after that.

Chart runs also got much longer: the biggest run of the 1960s was a number one that lasted 40
weeks, while the biggest of the 2010s was a number three that lasted 87.

## Data

From [TidyTuesday 2021-09-14](https://github.com/rfordatascience/tidytuesday/tree/main/data/2021/2021-09-14),
downloaded 2026-09-17, which credits
[Data.World](https://data.world/kcmillersean/billboard-hot-100-1958-2017#) by way of Sean
Miller, Billboard and Spotify. The TidyTuesday repository is CC0 1.0; the chart data and audio
measurements carry Billboard's and Spotify's own terms.

| File | Rows | Contents |
|---|---|---|
| `data/raw/billboard.csv` | 327,895 | one row per song per chart week, 1958-08-02 to 2021-05-29 |
| `data/raw/audio_features.csv` | 29,503 | Spotify measurements per song |

The files join on `song_id`, the title and performer concatenated. Audio coverage is uneven —
roughly two thirds of 1960s songs against nine in ten from the 2010s — which is a bias every
decade comparison has to account for, and which the story discusses rather than hides.

Spotify withdrew public access to the audio-features endpoint in November 2024, so no
comparable data exists past 2021.

## Layout

```
data/raw/          committed, never modified
data/processed/    written by the scripts
docs/              the story (index.html), documentation, and figures
docs/figures/      final SVGs, with each chart's values as CSV under data/
notebooks/         exploration and the decisions behind the pipeline
src/               clean.py -> features.py -> visualize.py
```

## Documentation

- [docs/processed-schema.md](docs/processed-schema.md) — every column in the processed files
- [docs/cleaning-decisions.md](docs/cleaning-decisions.md) — each problem found in the data, the
  options considered, and why we chose what we chose
- `notebooks/initial_eda.ipynb` — first look at the raw files
- `notebooks/cleaning_decisions.ipynb` — the rows behind each cleaning rule
- `notebooks/final_analysis.ipynb` — the sensitivity checks the story refers to

Worth knowing before reading any figure: one song charted twice in the same week in 1990 and
both rows are real; the source `weeks_on_chart` counts rows rather than weeks; some durations
belong to album versions of songs that charted as edited singles; and Billboard changed the
Hot 100 formula five times over this period, so an era comparison is never only about music.
